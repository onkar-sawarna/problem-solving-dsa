# Two Pointers

Sorted, or both sides already ordered. One index reads. The other writes, or the two ends move toward each other. Each index only moves forward.

## Write index

`j` reads. `i` writes, and it only moves when the value is kept.

```cpp
int i = 0;
for (int j = 1; j < n; j++) {
    if (nums[j] != nums[i]) {
        i++;
        nums[i] = nums[j];
    }
}
return i + 1;
```

Keep at most two copies by comparing with the value two places back: `nums[j] != nums[i - 2]`, and start both indexes at 2.

## Merge from the end

Empty slots are at the end of `nums1`, so write from `m + n - 1`. The larger of the two ends goes there. After the loop, copy anything left in `nums2`. Anything left in `nums1` is already in place.
