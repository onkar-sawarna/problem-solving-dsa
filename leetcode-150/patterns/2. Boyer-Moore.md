# Boyer-Moore

One value appears more than half the time. Find it in one pass with two integers.

Same value adds 1. A different value subtracts 1. Count 0 means the old candidate was cancelled, so the current value becomes the candidate. The majority cannot be fully cancelled, so it is the value left at the end.

```cpp
int candidate = 0, count = 0;
for (int x : nums) {
    if (count == 0) candidate = x;
    if (x == candidate) count++;
    else count--;
}
return candidate;
```
