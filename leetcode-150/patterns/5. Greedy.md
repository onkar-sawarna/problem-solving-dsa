# Greedy

One left-to-right fact is enough. If you can say why a later choice cannot beat it, keep that fact and move on.

## Can you reach the end?

`nums[i]` is the farthest jump from index `i`. `furthest` is the largest index reachable so far.

```cpp
int furthest = 0;
for (int i = 0; i < n; i++) {
    if (i > furthest) return false;
    furthest = max(furthest, i + nums[i]);
}
return true;
```

If `i` is past `furthest`, nothing already seen can land there. A zero at that gap blocks the end.

```text
[2, 3, 1, 1, 4]
i = 0 reaches 2
i = 1 reaches 4, which is the last index

[3, 2, 1, 0, 4]
furthest stays 3
i = 4 is past 3, so the end is blocked
```

## Fewest jumps

The last index can be reached. Count the jumps.

`end` is where the current jump runs out. Inside that range, `furthest` is the best place the next jump can land. Reaching `end` spends one jump and opens the next range.

```cpp
int jumps = 0, furthest = 0, end = 0;
for (int i = 0; i < n - 1; i++) {
    furthest = max(furthest, i + nums[i]);
    if (i == end) {
        jumps++;
        end = furthest;
    }
}
return jumps;
```

```text
[2, 3, 1, 1, 4]
i = 0: furthest 2, the range ends, 1 jump, next range ends at 2
i = 1: furthest 4
i = 2: the range ends, 2 jumps, next range reaches the end
```

55 asks whether the end is reachable. This counts how many ranges it takes.
