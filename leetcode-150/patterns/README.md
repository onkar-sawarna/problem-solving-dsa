# Revise these before an interview

Read this page only. Open a pattern file when the skeleton is no longer automatic.

## How to practice

Take problems in list order. A problem is solved only when you can write it the next day without looking.

1. Read it once. Note the input, the output, and how big `n` is.
2. Check the table below, then the old folders. Do not open a finished solution.
3. If it matches a pattern you already have, close the page and write the code. If you get stuck, peek at the skeleton only, then close it and write again.
4. If it matches nothing after 15 minutes, ask for the pattern name only. Write the code yourself. Add the next numbered pattern file and one row in the table.
5. The next day, write that same problem again with everything closed.

Move on only after that rewrite works. If the next problem is the same pattern, write it with no help. If it is a new pattern, repeat step 4.
