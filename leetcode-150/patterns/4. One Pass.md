# One pass

The answer for today only depends on the best fact saved from earlier days. One left-to-right scan. No pair of indexes.

## Buy and sell once

`cheapest` is the lowest price at or before today. Selling today earns `price - cheapest`.

```cpp
int cheapest = prices[0];
int profit = 0;
for (int price : prices) {
    cheapest = min(cheapest, price);
    profit = max(profit, price - cheapest);
}
return profit;
```

The buy must be an earlier day. Moving one pointer from each end only checks symmetric pairs, so `[2, 4, 1]` returns 0 instead of 2.

`n` can be `10^5`. Checking every buy day against every later sell day is `O(n^2)` and misses the 1-second limit.

## Buy and sell as often as you want

Add every day that goes up. A longer climb is just the sum of its daily steps.

```cpp
int profit = 0;
for (int i = 1; i < n; i++) {
    if (prices[i] > prices[i - 1]) {
        profit += prices[i] - prices[i - 1];
    }
}
return profit;
```

121 keeps one sale: `price - cheapest`. Here every rise is its own sale.
