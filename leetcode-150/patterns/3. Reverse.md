# Reverse

Move a block inside an array without an extra array. Reverse a range, then reverse the pieces so the original order comes back.

## Rotate right by k

`k %= n` first. Rotating `n` steps changes nothing, and `k` can be larger than `n`.

```cpp
k %= n;
reverse(nums.begin(), nums.end());
reverse(nums.begin(), nums.begin() + k);
reverse(nums.begin() + k, nums.end());
```

Whole reverse, first `k`, then the rest. The old tail is now at the front, in its original order.

```text
[1, 2, 3, 4, 5, 6, 7], k = 3
[7, 6, 5, 4, 3, 2, 1]
[5, 6, 7, 4, 3, 2, 1]
[5, 6, 7, 1, 2, 3, 4]
```

Shifting one position, `k` times, is `O(nk)`. Here both can be `10^5`, so that misses the 1-second limit. Three reversals are `O(n)` and use no extra array.
